## Objectives

- Understand fundamental computer networking concepts.
- Learn common networking commands in Linux and Windows.
- Configure and simulate networks using Cisco Packet Tracer.
- Analyze network traffic using Wireshark.
- Understand error control, flow control, and subnetting.
- Explore network scanning and host discovery.
- Implement client–server communication using sockets.
- Understand ICMP, TCP, UDP, and raw socket programming.

## Tools and Technologies

- Linux and Windows
- Cisco Packet Tracer
- Wireshark
- Nmap
- TryHackMe
- TCP/IP networking
- Socket programming
